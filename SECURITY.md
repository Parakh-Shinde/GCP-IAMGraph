# Security Policy

## Supported version

The latest release on the default branch receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could put users at risk. Contact the maintainer privately through the profile address listed in the repository.

## Credential safety

GCP IAMGraph does not require live credentials for its included examples. Never commit service-account keys, access tokens, real asset exports, Terraform state, or confidential organization policies.
